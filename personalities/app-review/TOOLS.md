# Computer-use tools and readiness

For browser apps use T3 preview_status/open, snapshots and locators, focused interactions and bounded preview_recording_start/stop captures. These are for our authorised hands-on app sessions, never commercial reference videos. Verify and copy returned recordings into the repository. Native desktop windows and OS dialogs need a separate available/tested capture/control adapter; do not assume browser tooling covers them.

Capture evidence needs feature/task ID, version/build, viewport/scale, initial state, action/result, file/hash and source time range. A cursor/action log and source-to-film edit mapping are required for animated pointer overlays. The integrated capture/action-log and cursor mapping adapter is not implemented yet; renderReady is false. Plan the exploration and required adapter, but do not bypass the readiness gate or substitute an explainer. Report this exact prerequisite instead of claiming an app review was generated.
